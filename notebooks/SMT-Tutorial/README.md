# Phrase-Based Statistical Machine Translaiton (PBSMT) Tutorial

ဒီနေ့ SMT pipeline အစအဆုံး ကို လက်တွေ့ run ပြခဲ့တယ်။  
မြန်မာ ကနေ ရခိုင်၊ ရခိုင် ကနေ မြန်မာ ဘာသာပြန်တာကို ဥပမာအနေနဲ့ ထားပြီး ဒေတာမှာ ပါနေတဲ့ အမှားတွေကို cleaning လုပ်တာကနေ နောက်ဆုံး BLEU, chrF++ ရလဒ်တွေကို တွက်ထုတ်တဲ့ အဆင့်အထိပါ အဆင့်ဆင့်မို့ တကယ်တမ်း တတ်ကျွမ်းနားလည်ဖို့က လက်တွေ့ လုပ်ကြည့်ကြဖို့ အကြံပေးချင်ပါတယ်။
